# NotebookLM Slide Deck Support

## Overview

NotebookLM supports native slide deck generation as a first-class artifact type. The output is a **PDF file** — not PPTX or Google Slides. There is no native PPTX export from the NotebookLM API.

## API Methods (notebooklm-py)

### Generate

```python
status = await client.artifacts.generate_slide_deck(
    notebook_id,
    slide_format=SlideDeckFormat.DETAILED_DECK,  # or PRESENTER_SLIDES
    slide_length=SlideDeckLength.DEFAULT,          # or SHORT
    instructions="Optional custom instructions",
)
# Returns: status.task_id
```

### Poll / Wait

```python
final = await client.artifacts.wait_for_completion(
    notebook_id,
    task_id,
    timeout=600,
    poll_interval=10,
)
# Returns: final.is_complete, final.is_failed, final.url, final.error
```

### Download

```python
path = await client.artifacts.download_slide_deck(
    notebook_id,
    output_path,
    artifact_id=artifact_id,  # optional, uses latest if omitted
)
```

### List / Delete

Slide decks appear in the general artifacts list alongside audio and infographics:

```python
artifacts = await client.artifacts.list(notebook_id)
await client.artifacts.delete(notebook_id, artifact_id)
```

## Formats

| Format | Description |
|--------|-------------|
| `DETAILED_DECK` | Full slide deck with detailed content per slide (default) |
| `PRESENTER_SLIDES` | Concise presenter-style slides with speaker notes focus |

## Lengths

| Length | Description |
|--------|-------------|
| `DEFAULT` | Standard length (default) |
| `SHORT` | Shorter, more condensed deck |

Note: Unlike audio, there is no `LONG` option for slide decks.

## Output Format

- **File type:** PDF
- **Not available:** PPTX, Google Slides, ODP, or any editable format
- The PDF is generated by NotebookLM's Gemini backend and reflects the notebook's source content

## Wrapper Methods (notebooklm_wrapper.py)

The `NotebookLMWrapper` class exposes:

- `generate_slide_deck(notebook_id, instructions, slide_format, slide_length)` → `{"task_id": ..., "status": "started"}`
- `download_slide_deck(notebook_id, output_path, artifact_id)` → local file path string
- `wait_for_audio(notebook_id, task_id, timeout, poll_interval)` → completion status dict (shared with audio polling)
- `list_artifacts(notebook_id, artifact_type="slide-deck")` → filtered artifact list
- `get_artifact(notebook_id, artifact_id)` → artifact detail dict
- `delete_artifact(notebook_id, artifact_id)` → bool
- `get_audio_status(notebook_id, task_id)` → task status dict (shared with audio)

## Existing Integration

`artifact_manager.py` already has a `generate-slides` subcommand that wraps `generate_slide_deck()`. The new `slides_manager.py` is a standalone script focused exclusively on slide deck operations, following the same pattern but without the audio/infographic commands.

## Limitations

- Output is PDF only — no editable format
- No `LONG` length option (unlike audio)
- Generation can take several minutes depending on notebook size
- Rate limits apply (same as other NotebookLM operations)
- Requires authenticated session via `notebooklm_wrapper.py`
